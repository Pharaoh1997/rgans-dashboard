Cara Menyalakan PS & Stik
⚠️ PENTING: Station 1, 2, & 5 menggunakan sistem PS3 HEN. Wajib Enable HEN agar game bisa dimainkan!
1

Nyalakan PS & Stik Controller

Tekan tombol berlogo [PS] di tengah stik controller 1 sampai lampu menyala.

💡 Atau tekan tombol Power di depan mesin konsol PS sampai bunyi "BIP". TV otomatis menyala via smartplug.

2

Tekan / Pilih "Enable HEN" 🥚

Di layar utama menu PS3 (XMB), geser ke menu Game.

Arahkan kursor dan klik Enable HEN (ikon telur HEN).

✓ Tunggu beberapa detik sampai muncul notifikasi "HEN Enabled" di pojok layar. Sekarang game siap dimainkan!

3

Menghubungkan Stik 2 (Main Berdua)

Tekan tombol berlogo [PS] di tengah stik controller ke-2 untuk menghubungkan Player 2.

4

TV Belum Tampil Gambar?

Pastikan input TV berada di HDMI 1 atau HDMI 2 menggunakan tombol Input / Source di TV.

⚡ Station 3, 4 & PS 4 TIDAK PERLU Enable HEN! Langsung siap dimainkan.
1

Nyalakan PS & Stik Controller

Tekan tombol berlogo [PS] di tengah stik controller 1 sampai lampu stik menyala.

💡 Atau tekan tombol Power di depan mesin konsol sampai bunyi "BIP". TV otomatis menyala via smartplug.

2

Langsung Main (Tanpa Enable HEN)

Pilih game yang ada di layar utama, langsung tekan untuk mulai bermain tanpa perlu enable HEN.

3

📌 NOTES: Mau Main Game Lain?

Koleksi game lengkap lainnya tersimpan di:

Menu Daftar Game ➔ Pilih Playstation 3

Semua koleksi ratusan game lengkap siap dipilih dan langsung dimainkan!

4

Menghubungkan Stik 2 (Main Berdua)

Tekan tombol berlogo [PS] di stik ke-2 untuk langsung bergabung sebagai Player 2.
